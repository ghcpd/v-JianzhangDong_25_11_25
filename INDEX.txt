GETTING HELP:

  Q: Setup fails - dependencies won't install
  A: Ensure Python 3.8+ is installed. Try: pip install --upgrade pip

  Q: Tests fail to start Flask app
  A: Check if port 5000 is available. Close other Flask instances.

  Q: Virtual environment issues
  A: Delete 'venv' folder and rerun setup script

  Q: Permission denied on scripts
  A: Linux/Mac: Run chmod +x setup.sh run_test.sh

  Q: Where are test logs?
  A: Check logs/test_run.log for detailed execution logs

  Q: How to verify all files present?
  A: Run: python verify_setup.py
