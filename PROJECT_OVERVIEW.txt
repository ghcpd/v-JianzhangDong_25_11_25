================================================================================
                           SECURITY FIXES APPLIED
================================================================================

1. SQL INJECTION (VULN-001)
   Before:  sql = f"SELECT * FROM users WHERE name LIKE '%{name}%'"
   After:   sql = "SELECT * FROM users WHERE name LIKE ?"
            cur.execute(sql, ('%' + name + '%',))
   Impact:  Prevents database manipulation attacks

2. INSECURE DESERIALIZATION (VULN-002)
   Before:  profile = pickle.loads(data)
   After:   profile = json.loads(data.decode('utf-8'))
            + validation
   Impact:  Eliminates remote code execution risk

3. COMMAND INJECTION (VULN-003)
   Before:  os.system("echo Running: " + cmd)
   After:   Input validation + logging only
   Impact:  Prevents arbitrary command execution

4. TEMPLATE INJECTION (VULN-004)
   Before:  template = "<h1>Hello %s</h1>" % name
            return render_template_string(template)
   After:   safe_name = escape(name)
            template = "<h1>Hello {{ name }}</h1>"
            return render_template_string(template, name=safe_name)
   Impact:  Prevents server-side template injection

5. HARDCODED SECRETS (VULN-005)
   Before:  API_KEY = "AKIA_EXAMPLE_HARDCODED_KEY_123456"
   After:   API_KEY = os.environ.get('API_KEY')
   Impact:  Protects sensitive credentials

6. WEAK PASSWORDS (VULN-006)
   Before:  USERS = {"alice": {"password": "password123"}}
            if user["password"] == password:
   After:   USERS = {"alice": {"password_hash": generate_password_hash(...)}}
            if check_password_hash(user["password_hash"], password):
   Impact:  Protects user credentials with hashing

7. DEBUG MODE (VULN-007)
   Before:  app.run(debug=True)
   After:   debug_mode = os.environ.get('FLASK_DEBUG', 'False').lower() == 'true'
            app.run(debug=debug_mode, host='127.0.0.1')
   Impact:  Prevents information disclosure in production
